---

Use the shared SKOR authentication flow, then make your first protected Modular API request.

## Prerequisites

Before you begin, make sure you have:

- A SKOR API `client_id`
- A SKOR API `client_secret`
- The SKOR Modular API base URL for your environment

## Choose a base URL

<Tabs>
  <Tab title="Production">
    `https://api.skortorent.com/api/v1`
  </Tab>
  <Tab title="Sandbox">
    `https://dev-api.skortorent.com/api/v1`
  </Tab>
</Tabs>

Choose an environment once. The Production and Sandbox tabs stay synchronized across the examples on this page. Use credentials issued for the selected environment.

<Steps>
  <Step title="Generate an access token">
    Send a token request to [Generate Access Token](/api-reference/token/generate-access-token) using HTTP Basic Authentication. Use your `client_id` as the username and your `client_secret` as the password.

    <Tabs>
      <Tab title="Production">
        ```bash
        curl -X POST "https://api.skortorent.com/api/v1/authenticate/token" \
          -u "$SKOR_CLIENT_ID:$SKOR_CLIENT_SECRET"
        ```
      </Tab>
      <Tab title="Sandbox">
        ```bash
        curl -X POST "https://dev-api.skortorent.com/api/v1/authenticate/token" \
          -u "$SKOR_CLIENT_ID:$SKOR_CLIENT_SECRET"
        ```
      </Tab>
    </Tabs>

    The response returns a one-hour token for authenticated API requests.
  </Step>

  <Step title="Store the token securely">
    Treat the token as a secret. Do not expose it in client-side code, logs, or public repositories.

    ```bash
    export SKOR_ACCESS_TOKEN="<token>"
    ```
  </Step>

  <Step title="Call protected endpoints">
    Send the token as a bearer token in the `Authorization` header. This example calls [Get All Tenants](/api-reference/tenants/get-all-tenants).

    <Tabs>
      <Tab title="Production">
        ```bash
        curl "https://api.skortorent.com/api/v1/tenants/get-all-tenants" \
          -H "Authorization: Bearer $SKOR_ACCESS_TOKEN"
        ```
      </Tab>
      <Tab title="Sandbox">
        ```bash
        curl "https://dev-api.skortorent.com/api/v1/tenants/get-all-tenants" \
          -H "Authorization: Bearer $SKOR_ACCESS_TOKEN"
        ```
      </Tab>
    </Tabs>
  </Step>
</Steps>

<Tip>
  Need credentials or help with authentication? Contact [info@skortorent.com](mailto:info@skortorent.com).
</Tip>
