The SKOR Modular API reference is generated from the OpenAPI specification.

Use the **Modular API Reference** section in the sidebar to browse webhook and tenant endpoints. Generate a shared token with [Generate Access Token](/api-reference/token/generate-access-token) (see the [Authentication guide](/authentication)), then use `Authorization: Bearer <token>` when calling protected endpoints.
